# Functional Differentiation Research

中文名称：学习驱动的功能分化、独立提取与复用研究（原本地项目名：假想猜测）。

这是一个开放的探索性研究项目。我们研究：未经预分配功能分块的循环网络，是否能通过学习形成可因果区分的功能组织；其中的功能部分能否脱离母网独立运行，并在更换另一交互对象后复用。完整猜想尚未得到验证。

## 核心猜想

两个具备不同信息处理能力的系统A、B，向可学习的中间模块C提供经历与反馈。C可能学习到具有不同因果贡献的内部计算，并在合适条件下形成可提取、可复用的功能部分。最初框架称为PIM（Persistent Intermediary Module），这个名称不预设已经产生第三种模型或跨回合持久记忆。

“能够预测”“局部删除导致损伤”“独立提取成功”“换对象仍可用”是依次增强的主张，需要分别验收。当前简化任务是两个固定参数、同一AR(2)模型族的独立来源及混合观测；它只检验组件级前置，没有完整A/B相互作用。

## 可检验预测

| 编号 | 预测或条件命题 | 所需证据 | 截至2026-11-15 |
|---|---|---|---|
| P1 | 降低情境识别负担后，同规模递归表示和普通训练可以完成基础预测 | 显式合法构造、新样本验收、固定预算普通学习及冻结递归对照 | 在登记的简化任务上通过 |
| P2 | 若学习形成目标相关的组织，应有状态集合对一个目标产生更强的联合因果影响 | 冻结网络、发现/确认分离、同操作随机与幅度匹配随机控制 | 旧P2匹配失效；新P2B通过，见下文 |
| P3 | 若该功能部分可独立提取，仅保留它也应维持目标功能 | 实际隔离递归及读出、导出文件不调用母网 | 当前任务未执行；历史多轮保持失败 |
| P4 | 若它可复用，更换非目标来源对象后仍应有效 | 锁定导出物、新对象、明确接口与随机/从头训练对照 | 未建立支持证据 |
| P5 | 若损伤/修复诱导促进目标分工，应提高独立保持和复用，而非只提高鲁棒性 | 匹配预算的诱导对照及完整后续链 | 候选途径，当前暂停 |

P2–P5不是结果承诺。功能分化不要求坐标集合互斥，也不预设一定形成整齐模块。没有找到某类坐标子集不能证明所有分布式功能子空间均不存在。

## 当前结果

- 固定动力学简化任务，12单元GRU加线性头：人工构造两个种子、两个目标共4/4通过；另数值路径复核通过。
- 普通网络从默认随机初始化学习，固定预算4/4通过；冻结递归、仅训练读出对照0/4通过。主网MSE/参考MSE约1.00477–1.00611，对照约2.05674–2.40661。
- P2旧幅度匹配有9个案例超过登记上限，整体MATCHING_INVALID；该失败保留。改用双边等幅收缩，先通过已知正例与因果空白校准，再在新确认数据上检验原锁定网络。
- 新P2B主网4/4局部选择性与4/4学习相关比较通过，独立数值路径审计通过。冻结递归控制也有4/4局部门槛通过，训练前控制0/4；不能把局部选择性说成训练网络独有。
- 这支持本设定和干预算子下的局部因果选择性及相对控制的增强。控制预测能力未匹配，仍不能排除性能混杂；独立提取P3与换对象复用P4均未运行，完整猜想尚未验证。
- 旧隐藏情境任务、后验槽递推和独立保持等失败保留，见[证据与失败边界](EVIDENCE.md)。不能用新任务的通过改写旧任务。
